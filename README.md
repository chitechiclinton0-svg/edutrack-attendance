# EduTrack Attendance

EduTrack is a static HTML, CSS, and JavaScript attendance prototype. It runs in the browser and does not require a build step or server.

## Publish with GitHub Pages

1. Put `index.html`, `script.js`, and `style.css` in the root of a public GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/(root)`, then save.
4. Open the Pages URL shown in the repository settings.

## Data and privacy

This prototype stores account and attendance data in the current browser using local storage. Passwords are stored in plain text, there is no server-side authentication or shared database, and records do not sync between devices. It is not suitable for real student or sensitive personal information.
